# SoRa

**Your AI assistant, powered by Z.AI.** SoRa is a mobile AI chat application built around one cloud assistant and a persistent, on-device conversation history.

## Product

- One assistant and one remote model endpoint: the SoRa API backed by Z.AI `glm-4-plus`.
- OpenAI-compatible chat completions with token-by-token Server-Sent Events streaming.
- Conversation history stored locally in the app database and available after the app is closed and reopened.
- Previous messages from the active conversation are sent as context with each chat request so the assistant can continue the discussion.
- Search, pin, rename, export and delete conversations from the history drawer.
- Voice input and spoken responses where the device supports them.
- Image and file attachments where supported by the active server and app client.
- Light and dark themes, Russian-first UI and additional interface languages.

SoRa does not offer a local GGUF model catalogue or model download screen. The AI response is generated by the configured SoRa cloud API. The app keeps its saved chat history on the device; only the messages and context required for a request are sent to the server.

## Privacy and data

- Chat sessions are persisted in the app's local database.
- Closing or reopening the app does not intentionally clear saved conversations.
- The server receives the message list included in each request; it cannot access other local app data.
- Do not place a private provider key in the APK. Any server-side provider credentials belong in the server's environment secrets.
- Review the deployed server's privacy policy and retention configuration before public release.

## Development

### Requirements

- Node.js version specified by `.nvmrc` (currently Node.js `>=22.21.0`).
- Yarn Classic `1.22.x`.
- Android SDK/NDK for Android builds.
- Xcode and CocoaPods only when building the iOS target.

### Install and run

```bash
nvm use
yarn install
yarn start
yarn android
```

### Source checks

```bash
yarn lint
yarn typecheck
yarn test
yarn l10n:validate
node scripts/verify-fonts.js
```

### Android APK

```bash
cd android
./gradlew --no-daemon --build-cache assembleProdDebug
```

The production-debug package is for device testing. A store release must use a release keystore and pass package-signature and installation checks.

## Project layout

```text
src/
├── api/          OpenAI-compatible SoRa server client and completion engines
├── components/   Chat, history drawer, voice, settings and shared UI
├── database/     Local chat persistence and migrations
├── hooks/        Chat, navigation and voice hooks
├── locales/      Interface translations
├── repositories/ Persistence access layer
├── screens/      Chat, onboarding, settings and app information
├── services/     SoRa initialization and app services
├── store/        Observable app and chat state
└── utils/        Chat formatting, export, memory and platform helpers
```
